# 🧪 Test Data Generator & Store - Web Edition

גרסת Web אינטראקטיבית ומתקדמת של אפליקציית ה-CLI **"Test Data Generator & Store"**.  
האפליקציה בנויה ב-**HTML5, CSS3 ו-Vanilla JavaScript בלבד (ES6+)**, פועלת באופן עצמאי לחלוטין בצד הלקוח (Client-Side), ללא שרת (No Backend) וללא בסיס נתונים (No Database).

---

## 🌟 מאפיינים עיקריים

1. **נאמנות מוחלטת לאפליקציית המקור (CLI Specification):**
   - יישום מדויק של כל האלגוריתמים מתוך `logic.py` (אלגוריתם Luhn לת"ז ישראלית, מספרי נייד ישראליים 05X-XXXXXXX, מאגר שמות פרטיים ומשפחה עם מנגנון מניעת נעילה, גזירת כתובות דוא"ל).
   - הבטחת ייחודיות של 100% בתוך כל אצווה (Uniqueness Guarantee עם מעקב `_seen`).
   - ייצוא קובצי CSV תקניים עם קידוד **UTF-8 with BOM** (`\uFEFF`) לפתיחה ישירה ומושלמת ב-Microsoft Excel.
   
2. **ממשק משתמש כפול (Dual Interface):**
   - **ממשק גרפי מודרני (Dashboard GUI):** ניווט מהיר לפי שלבי המערכת (תפריטים 1 עד 5), טפסים עם ולידציה מיידית, תצוגת דוח ייחודיות מפורט, וטבלאות נתונים אינטראקטיביות עם דפדוף (Pagination).
   - **אמולטור מסוף אינטראקטיבי (CLI Terminal Emulator):** מסוף אותנטי המציג את תפריט ה-CLI המקורי, כותרות ANSI (Cyan, Green, Yellow, Red), הנחיות קלט אינטראקטיביות ומקשי פקודה מהירה.

3. **שכבת אחסון וירטואלית ב-Browser (In-Browser Virtual File System):**
   - שימוש ב-`localStorage` לסימולציית ספריית `output/`.
   - תמיכה בהורדה ישירה של קובצי CSV למחשב האישי.
   - תמיכה בייבוא (Upload / Import) של קובצי CSV חיצוניים לצפייה ולתצוגה מקדימה.
   - תיקון באג השחתת הנתונים השקט בהוספה (BUG-CLI-003): התאמת סכמת עמודות (Schema Alignment) אוטומטית בעת Append.

## 🚀 הוראות הפעלה

אין צורך בהתקנת ספריות, אין צורך ב-Node.js, אין צורך בשרת מקומי:

1. פתח את תיקיית `WEB`:
   ```text
   c:\Users\user\Documents\MyProject\AiNative\class04NEW_PROJECT\WEB
   ```
2. לחץ לחיצה כפולה על הקובץ **`index.html`** כדי לפתוח אותו בכל דפדפן מודרני (Google Chrome, Microsoft Edge, Mozilla Firefox, Apple Safari).
3. האפליקציה תיטען מיד ותאפשר לך להתחיל לייצר נתונים!

## 📋 מיפוי תפריטי המערכת

| מספר | שלב | תיאור הפעולה |
| :---: | :--- | :--- |
| **1** | **Set Record Count** | הזנת כמות רשומות (1 עד 100,000) עם אימות קלט מוקפד ולחצני קיצור (10, 50, 100, 1,000, 10,000, 100,000). |
| **2** | **Select Fields** | בחירת שדות: Full Name, Email, Phone, ID Number. תמיכה בבחירה גרפית או בהזנת מספרי שדות בסגנון CLI (`1,2,4` או `all`). |
| **3** | **Generate & Validate** | הפעלת מחולל הנתונים, הפקת דוח ייחודיות מפורט לכל שדה (100% Unique), תצוגה מקדימה בסגנון טרמינל וטבלת רשומות מלאה. |
| **4** | **Save to CSV** | שמירה בטוחה לדיסק הווירטואלי והורדה ישירה עם קידוד UTF-8 BOM. טיפול חכם בקבצים קיימים (Append / Overwrite). |
| **5** | **View Existing Files** | סייר קבצים בתיקיית `output/` הווירטואלית, הצגת גודל וכמות רשומות, תצוגה מקדימה טבלאית (20 שורות ראשונות) ואפשרות הורדה או מחיקה. |
| **0** | **Reset / Exit** | איפוס מצב הסשן והגדרות הבאצווה לברירת המחדל. |

## 🛡️ עמידה בדרישות QA ותיקוני תקלות

האפליקציה כוללת מענה מלא לכל הממצאים מדוח ה-QA (`04_Execution_and_Bug_Reports.md`):

- **BUG-CLI-003 (Schema Alignment on Append):** במצב הוספה (Append), המערכת בודקת את שורת הכותרות הקיימת ומצמידה את הערכים החדשים לעמודות התואמות, ללא עיוות והסטת נתונים.
- **BUG-CLI-004 (Stale Session Invalidation):** שינוי כמות רשומות או שדות מאפס אוטומטית את הבאצווה הקודמת ומציג התראה ברורה למשתמש.
- **BUG-CLI-005 (Case-Insensitive .csv):** בדיקת סיומת הקובץ מתבצעת ללא תלות באותיות גדולות/קטנות למניעת סיומת כפולה כגון `.CSV.csv`.
- **אלגוריתם Luhn תקין:** מיושם באופן זהה למשרד הפנים הישראלי עבור תעודות זהות בנות 9 ספרות.
