# Test Data Generator & Store
## מחולל ומנהל נתוני בדיקה – CLI Application

> אפליקציית CLI ב-Python לייצור נתונים פיקטיביים מבוקרים לצרכי בדיקות תוכנה.

---

## מבנה הפרויקט

```
class04NEW_PROJECT/
│
├── main.py        ← נקודת הכניסה (Entry Point)
├── cli.py         ← שכבת ממשק המשתמש (CLI / UI Layer)
├── logic.py       ← שכבת הלוגיקה העסקית (Business Logic)
├── storage.py     ← שכבת קבצים (File I/O Layer)
│
├── output/        ← תיקיית פלט ל-CSV (נוצרת אוטומטית)
│
└── tests/
    ├── test_logic.py    ← בדיקות יחידה ל-logic.py
    └── test_storage.py  ← בדיקות יחידה ל-storage.py
```

---

## הרצת האפליקציה

```bash
python main.py
```

**דרישות:** Python 3.10 ומעלה. אין צורך בחבילות חיצוניות.

---

## תפריט הראשי

| אפשרות | תיאור |
|--------|-------|
| **1** | הגדרת כמות רשומות לייצור (1 – 100,000) |
| **2** | בחירת שדות: שם מלא / מייל / טלפון / ת"ז |
| **3** | ייצור הנתונים + דוח ייחודיות (ללא כפילויות) |
| **4** | שמירה לקובץ CSV (יצירה / הוספה / החלפה) |
| **5** | צפייה בקבצי CSV קיימים |
| **0** | יציאה |

---

## השדות הזמינים לייצור

| מספר | שדה | תיאור |
|------|-----|-------|
| 1 | `full_name` | שם מלא רנדומלי בעברית/אנגלית |
| 2 | `email` | כתובת מייל תקינה (נגזרת מהשם) |
| 3 | `phone` | מספר טלפון ישראלי (פורמט 05x-xxxxxxx) |
| 4 | `id_number` | ת"ז ישראלית תקינה (ספרת ביקורת לפי Luhn) |

---

## ארכיטקטורה מודולרית

```
main.py
  └─► cli.py          (מנהל את תפריט ה-CLI והקלט)
        ├─► logic.py   (מייצר נתונים, מאמת ייחודיות)
        └─► storage.py (קורא וכותב קבצי CSV)
```

**כל שכבה עצמאית** – ניתן להחליף ממשק CLI בממשק Web מבלי לגעת ב-`logic.py` / `storage.py`.

## טיפול בשגיאות

- **קלט לא חוקי** – הודעת שגיאה ברורה, התפריט אינו קורס
- **כמות מחוץ לטווח** – ולידציה: 1 עד 100,000
- **שגיאות קבצים** – תפיסת `OSError` עם הודעה ידידותית
- **Ctrl+C** – יציאה נקייה בכל שלב
